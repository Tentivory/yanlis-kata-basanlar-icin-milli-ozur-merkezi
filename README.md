# Yanlış Kata Basanlar İçin Milli Özür Merkezi

Bu yazılım, asansörde **yanlış kata** basan vatandaşın vicdanını, binanın yönetim planını ve milletin ortak asansör onurunu kurtarmak için yazılmıştır.

Patates yoktur. Patates hiç olmadı. Patates olmayacak.

## Neden bu kadar ciddi?

Çünkü yanlış kata basmak sadece bir düğme hatası değildir. Bu, katlar arası güvenin zedelenmesidir. 7. kata gitmek isterken 8'e basmak, bir milletin yön duygusunu sarsar. Bu proje o sarsıntıyı **resmi dilekçe** formatında tedavi eder.

## Kurulum

```bash
python3 ozur.py
```

Python 3 yeter. İnternet gerekmez. Vicdan gerekir.

## Kullanım

Program şunları sorar:

1. İstediğin kat
2. Yanlışlıkla bastığın kat
3. Binanın adı (yoksa "İsimsiz Apartman Kompleksi" kabul edilir)
4. Özür seviyesi: `hafif`, `resmi`, `milli`

Sonra ekrana, yazdırılabilir, kapıya asılabilir, yöneticiye sunulabilir bir dilekçe basar.

## Örnek çıktı

Program, T.C. formatında tarih, sayı ve "gereğini arz ederim" cümlesi üretir. Cümleler kasten uzun tutulmuştur. Kısa özür, özür değildir.
